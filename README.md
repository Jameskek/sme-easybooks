## 💼 产品定位与商业价值

**SME EasyBooks Pro** 是专为**独资企业（Sole Proprietorship / Enterprise）、自由职业者（Freelancers）、中西医诊所、电商卖家与中小微企业**量身定制的单文件本地智能财务核算系统。

### 为什么小微企业主愿意付费购买？
1. **彻底摆脱高昂月费**：市面做账软件（AutoCount、SQL、Xero、Bukku）每年收取 RM 600 – RM 2,000 订阅费，而本系统支持**极简买断**。
2. **数据 100% 本地隐私安全**：无需连接外部第三方服务器，所有财务流水与利润报表完全存储在用户本地浏览器与本地 JSON 备份中，杜绝商业机密泄露。
3. **专业会计准则与勾稽平衡**：
   - 严格区分**现金流（Cash Flow）**与**权责发生制会计损益（Accounting P&L）**；
   - 自动生成**损益表（Statement of Profit or Loss）**与**资产负债表（Balance Sheet）**；
   - 自动校验 `总资产 = 负债 + 所有者权益` 资产负债平衡；
   - 支持一键导出 Bank CSV、Journal CSV 与一键打印生成 PDF 提交给外部报税会计师。

## 🚀 核心功能模块

- 📊 **经营概览看板**：实时呈现银行账面可用余额、年度累计营收、年度净利润与月度现金收支趋势表。
- ➕ **极速智能记账**：涵盖收入、日常费用、固定资产采购、业主注资与业主分红/提款 5 大类。
- 🏦 **银行流水明细账 (Bank Transactions)**：清晰追踪每一笔资金进出与运行中银行可用余额。
- 📖 **通用日记账 (General Journal)**：标准复式记账法借贷自动对冲。
- 📈 **专业损益表 (P&L)**：营业收入、销货成本（COGS）、毛利、营业管理费用分项与年度净利润。
- ⚖️ **资产负债表 (Balance Sheet)**：流动资产、固定资产、流动负债与权益分配一目了然。
- 🧾 **代垫款与报销管理**：精确记录老板/员工个人代垫企业费用，方便后续对账与还款。
- 💾 **一键数据备份与恢复**：支持一键导出带日期戳的 `.json` 加密备份文件，支持随时跨电脑导入恢复。
